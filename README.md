# 项目介绍
定位是个人助理,通过聊天形式进行资料搜索,任务规划,项目管理,情绪疏导等工作

# 执行流程
聊天->解决问题->分析当前聊天历史记录->形成长期记忆

# 记忆组成

## 短期记忆
个人数据集,包括称呼,记忆要点,关键事件,代办任务等,有效时间为1个月,每次聊天时作为系统提示词携带
## 长期记忆
- 数据库
    - 项目表/待办事项表
- 知识库
    - 聊天日记总结加入向量库,如果用户提问“你记得以前...”类似的问题时,从知识库中查询并回答

# 开发框架
    - 语言：python 3.12
    - 后端：fastapi
    - 数据库：sqlite/postgresql
    - ORM: sqlalchemy
    - 认证：jwt


## 项目结构
    -api 后端服务
        - route 接口/路由
        - service 业务逻辑
        - model 数据库模型
        - schema 数据校验模型
        - core 核心功能,如数据库连接,认证,授权等
    -web 前端服务
